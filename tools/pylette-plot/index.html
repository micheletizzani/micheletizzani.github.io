About

Pylette Plot is a lightweight Python library that extracts the dominant colour palette from any image using k-means clustering and renders the result as a clean, publication-ready figure.

It is designed for researchers and designers who need reproducible, aesthetic colour summaries — for figures in papers, design presentations, or exploratory data analysis. The output is a Matplotlib figure you can embed directly into any workflow.

Features

01

Palette Extraction

K-means clustering on RGB pixel space with configurable number of colours.

02

Publication Figures

Clean Matplotlib output, tight-layout ready, exportable to PNG, SVG, or PDF.

03

Zero Boilerplate

One function call — pass an image path, get a publication-ready figure.

04

Composable

Returns raw palette arrays for integration into custom visualization pipelines.

Quick Start

Install

pip install pylette-plot

Usage

from pylette_plot import plot_palette

# Extract 6 dominant colours and show the palette
fig = plot_palette("path/to/your/image.jpg", n_colors=6)
fig.savefig("palette.png", dpi=150, bbox_inches="tight")
